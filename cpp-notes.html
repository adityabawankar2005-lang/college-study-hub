Basic Concepts, Examples and Practice Programs

1. Introduction to C++

C++ is a general-purpose programming language. It is used for software development, games, applications and competitive programming.

Features of C++

  • Fast and efficient.
  • Supports procedural programming.
  • Supports object-oriented programming.
  • Provides functions, arrays and pointers.
  • Useful for learning programming and DSA.

2. Structure of a C++ Program

#include <iostream>
using namespace std;

int main() {
    cout << "Hello World!";
    return 0;
}
  • #include <iostream>: Enables input/output.
  • main(): Starting point of program execution.
  • cout: Displays output.
  • return 0: Indicates successful completion.

3. Variables and Data Types

A variable stores data in a program.

int age = 18;
float marks = 85.5;
double price = 99.99;
char grade = 'A';
string name = "Student";
bool passed = true;
  • int: Whole numbers.
  • float: Decimal numbers.
  • double: Decimal numbers with more precision.
  • char: A single character.
  • string: Text.
  • bool: True or false.

For string programs, include #include <string>.

4. Input and Output

#include <iostream>
using namespace std;

int main() {
    int a, b;

    cout << "Enter two numbers: ";
    cin >> a >> b;

    cout << "Sum = " << a + b;
    return 0;
}

cin takes input from the keyboard. cout displays output on the screen.

5. Operators in C++

  • Arithmetic: +, -, *, /, %
  • Relational: ==, !=, >, <, >=, <=
  • Logical: &&, ||, !
  • Assignment: =, +=, -=, *=
  • Increment: ++
  • Decrement: --
int a = 10, b = 3;

cout << a + b;
cout << a - b;
cout << a * b;
cout << a / b;
cout << a % b;

6. Conditional Statements

if-else

int age = 18;

if (age >= 18) {
    cout << "Eligible";
} else {
    cout << "Not Eligible";
}

else-if

int marks = 75;

if (marks >= 90) {
    cout << "Grade A";
} else if (marks >= 70) {
    cout << "Grade B";
} else if (marks >= 40) {
    cout << "Grade C";
} else {
    cout << "Fail";
}

Conditional statements execute code according to whether a condition is true or false.

7. Loops in C++

For Loop

for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}

While Loop

int i = 1;

while (i <= 5) {
    cout << i << " ";
    i++;
}

Do-While Loop

int i = 1;

do {
    cout << i << " ";
    i++;
} while (i <= 5);

Loops repeat statements while their conditions allow. A do-while loop executes at least once.

8. Arrays

An array stores multiple values of the same data type. Array indexing begins at zero.

int numbers[5] = {10, 20, 30, 40, 50};

cout << numbers[0];

for (int i = 0; i < 5; i++) {
    cout << numbers[i] << " ";
}

9. Functions

A function is a reusable block of code that performs a particular task.

int add(int a, int b) {
    return a + b;
}

int main() {
    cout << add(5, 3);
    return 0;
}

Functions make programs easier to organize, reuse and maintain.

10. Strings

A string stores a sequence of characters.

#include <iostream>
#include <string>
using namespace std;

int main() {
    string name = "C++ Programming";

    cout << name;
    cout << name.length();

    return 0;
}

11. Pointers

A pointer stores the memory address of an object.

int number = 10;
int* ptr = &number;

cout << number;
cout << *ptr;

The & operator obtains an address. The * operator can access the value at the address stored in a pointer.

12. Object-Oriented Programming (OOP)

  • Class: Blueprint for creating objects.
  • Object: Instance of a class.
  • Encapsulation: Organizes data and methods together.
  • Inheritance: Creates a class based on another class.
  • Polymorphism: Allows different behaviours through a common interface.
  • Abstraction: Hides implementation details.

Class and Object Example

#include <iostream>
#include <string>
using namespace std;

class Student {
public:
    string name;
    int rollNo;

    void display() {
        cout << name << " " << rollNo;
    }
};

int main() {
    Student s1;

    s1.name = "Aman";
    s1.rollNo = 1;
    s1.display();

    return 0;
}

13. Constructors

A constructor initializes an object when it is created. It has the same name as the class and no return type.

class Student {
public:
    int rollNo;

    Student() {
        rollNo = 1;
    }
};

14. Common Errors in C++

  • Forgetting semicolons.
  • Using variables before declaring them.
  • Misspelling variable names.
  • Using = instead of == in a comparison.
  • Missing curly braces or parentheses.
  • Accessing an array outside its valid range.

15. C++ Practice Programs

  4. Find the largest of three numbers.
  5. Print numbers from 1 to 100.
  6. Calculate the factorial of a number.

  10. Calculate the area of a rectangle.

16. How to Learn C++

  1. Understand basic syntax and data types.
  2. Practise input, output and operators.
  3. Learn conditions and loops.
  4. Practise arrays and functions.
  5. Study pointers and references.
  6. Learn classes, objects and OOP.
  7. Write small programs regularly.
