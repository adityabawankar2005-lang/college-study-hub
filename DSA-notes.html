1. What is Data Structure?

A data structure is a way of organizing and storing data so that it can be accessed and modified efficiently.

Examples: Array, Linked List, Stack, Queue and Tree.

2. Array

An array stores multiple elements of the same data type.

#include <iostream>
using namespace std;

int main() {
    int arr[3] = {10, 20, 30};

    for (int i = 0; i < 3; i++) {
        cout << arr[i] << " ";
    }

    return 0;
}

3. Linear Search

Linear search checks each element one by one until the required element is found. 

#include <iostream>
using namespace std;

int main() {
    int arr[5] = {10, 20, 30, 40, 50};
    int key = 30;

    for (int i = 0; i < 5; i++) {
        if (arr[i] == key) {
            cout << "Found at index " << i;
            break;
        }
    }

    return 0;
}

4. Stack

A stack follows LIFO: Last In, First Out. The last element inserted is removed first.

Operations: Push, Pop and Peek.

5. Queue

A queue follows FIFO: First In, First Out. The first element inserted is removed first.

Operations: Enqueue and Dequeue.

6. Time Complexity

  • O(1) — Constant time
  • O(log n) — Logarithmic time
  • O(n) — Linear time
  • O(n²) — Quadratic time
